픽창 판독기

양 팀 10명을 넣으면 0~10분, 10~20분, 20~30분, 30분 이후 구간별 우세와 5:5 한타 구도, 운영 난이도를 보여줘요. 내 포지션을 고르고 그 칸을 비워두면 지금 픽창 상황에 맞는 챔피언을 추천해요.

PC에서 롤을 켜고 PC 도우미를 실행하면 픽창의 포지션, 픽, 밴이 자동으로 입력돼요. 챔피언 이름은 초성(예: ㄹㄴㅌ)으로도 입력할 수 있어요.

1픽창 입력
내 포지션
선택: 중계 서버 없이 이 PC에서 전적 더 보기 (내 Riot API 키 필요)
클라이언트는 최근 20판 정도만 보여줘요. 내 Riot API 키를 넣으면 내 계정 경기를 최근 300판까지 받아요. 키는 이 PC에만 저장되고 Riot 서버에만 보내요.
아군
상대 (보이는 만큼만)

2챔프 추천
추천 챔피언

내 자리에 각 챔피언을 넣어보고 구간별 우세, 한타, 운영 난이도, 상대 라이너와의 라인전을 합쳐 순위를 매겨요. 이미 픽된 챔피언은 빠지고, 챔프폭은 이 브라우저에 저장돼요.
