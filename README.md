# 픽창 판독기

리그 오브 레전드 픽창에서 양 팀 10명을 넣으면 아래 내용을 보여주는 웹 페이지예요.

- 0~10분, 10~20분, 20~30분, 30분 이후 구간별 우세
- 5:5 한타 구도 (이니시, 앞라인, 보호, 물리/마법 피해 비율)
- 아군 운영 난이도와 이번 판 게임 플랜
- 내 포지션을 고르면 지금 픽창 상황에 맞는 추천 챔피언 (내 챔프폭 표시·필터 가능)
- `이름#태그`로 내 최근 랭크 기록을 불러와 포지션별 챔프폭 자동 채우기
- 밴 반영, 내 라인 밴 추천, 상대 라이너를 모를 때(먼저 뽑을 때) 블라인드 안전도
- 챔피언 이름 초성 입력 (예: `ㄹㄴㅌ` → 레넥톤, `ㅆㄹㅅ` → 쓰레쉬)
- **PC 도우미**를 켜두면 롤 클라이언트 픽창의 포지션·픽·밴이 자동으로 입력돼요

**바로 쓰기:** https://wandadj.github.io/lol-pick-reader/

## PC 도우미

롤 클라이언트가 켜진 PC에서 도우미를 실행하면 픽창 정보를 자동으로 읽어서 판독기에 채워줘요. Mac과 Windows 둘 다 돼요.

**자동으로 채워지는 것:** 내 포지션, 아군 픽(확정·고민 중), 공개된 상대 픽(포지션은 챔피언으로 추정), 양 팀 밴, 지금 내 차례인지

**내 챔프폭:** 클라이언트에 로그인한 계정의 최근 전적과 챔피언 숙련도로 포지션별 챔프폭을 자동으로 채워요. Riot API 키가 필요 없어서 누구나 쓸 수 있어요. 클라이언트는 최근 20판 정도만 보여주지만, 도우미가 읽을 때마다 이 PC(`~/.lol-pick-reader/`)에 **최근 300판까지 쌓아요.** 중계 서버가 연결돼 있고 내 아이디가 등록돼 있으면 같은 기록을 서버에도 쌓아요 (Riot API 요청 없이, 내 기록만).

**전적 더 보기 (선택):** 도우미 페이지의 "전적 더 보기" 칸에 내 Riot API 키(Personal Key면 충분)를 넣으면 Riot 공식 기록에서 **내 계정 경기만** 최근 300판까지 받아요.
- 키는 이 PC의 `~/.lol-pick-reader/config.json`에만 저장되고(내 계정만 읽을 수 있는 권한), Riot 서버에만 보내요. 페이지나 GitHub로는 나가지 않아요.
- 키 저장·삭제는 도우미가 띄운 페이지에서만 할 수 있어요. 다른 사이트가 몰래 바꾸지 못해요.
- 처음엔 요청 한도(2분에 100회) 때문에 300판을 받는 데 6~7분 걸려요. 받는 동안에도 받은 만큼 바로 반영되고, 다음부터는 새로 한 경기만 받아요.
- 랭크 경기는 Riot 기록에 정확한 포지션이 있어서 추정 없이 정확해요.

**가져오지 않는 것:** 아군·상대의 닉네임, 계정 정보. 솔로 랭크에서 가려진 닉네임을 드러내는 건 Riot 정책 위반이라 도우미는 챔피언·포지션·밴 정보만 써요.

### 설치
[Releases](https://github.com/WandaDJ/lol-pick-reader/releases)에서 내 컴퓨터에 맞는 파일을 받아 압축을 풀어요.

| 컴퓨터 | 파일 | 처음 실행할 때 |
|---|---|---|
| Windows | `PickHelper-Windows.zip` → `PickHelper.exe` | "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** |
| Mac (Apple 실리콘) | `PickHelper-Mac.zip` → `PickHelper` | "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기** |

서명되지 않은 개인 프로젝트라 처음 한 번 경고가 떠요. 코드는 이 저장소의 `helper/pick_helper.py`가 전부예요.

Python이 있으면 파일을 받지 않고 바로 실행해도 돼요 (Python 3.9 이상, Intel Mac도 이 방법으로).
```bash
python3 helper/pick_helper.py
```

### 사용
1. 도우미를 실행하면 브라우저에서 `http://127.0.0.1:27150/`이 자동으로 열려요.
2. 롤 클라이언트를 켜고 큐를 돌리면, 픽창이 시작될 때부터 칸이 자동으로 채워져요.
3. 직접 고치고 싶으면 상단의 **자동 채우기**를 끄면 돼요.
4. 끝낼 때는 도우미 창을 닫으세요.

**자동 업데이트:** 도우미는 켤 때마다 GitHub Pages에서 도우미 코드 최신본을 확인해서, 새 버전이면 받아서 그걸로 실행해요 (`~/.lol-pick-reader/`에 저장). 새 코드가 실행에 실패하면 설치된 버전으로 실행해요. 켜져 있는 동안엔 10분마다 페이지 최신본을 받고, 픽창이 아닐 때 브라우저가 자동으로 새로고침돼요. 그래서 한 번 설치하면 다시 받을 필요가 거의 없어요.

모든 통신은 내 PC 안에서만 이뤄지고, 도우미가 밖으로 접속하는 건 페이지와 도우미 최신본을 GitHub Pages에서 받아올 때뿐이에요. 클라이언트 로컬 API(LCU)는 Riot이 공식 지원하는 기능이 아니라서 클라이언트 업데이트 뒤에 동작이 바뀔 수 있어요.

## 챔피언별 상황 문장

게임 플랜의 "내 역할"에는 챔피언마다 써둔 문장이 상황에 맞게 섞여 나와요 (172개 챔피언 × 7개 문장).

| 항목 | 보여주는 때 |
|---|---|
| 강해지는 시점 | 항상 |
| 0~10분 / 10~20분 / 20분 이후 | 각 구간 할 일 아래 |
| 이기고 있을 때 / 지고 있을 때 | 내 라인 우세가 56% 이상 / 44% 이하일 때 |
| 상대할 때 | 그 챔피언이 내 맞라이너일 때 (바텀은 상대 원딜·서폿 둘 다) |

- 원본은 `data/notes/*.json`이고, 고친 뒤 `python scripts/build_notes.py`를 실행하면 `data/champ-notes.json`이 만들어져요.
- 페이지는 이 파일을 한 번 받아서 브라우저에 저장해두고, 버전이 바뀌었을 때만 새로 받아요. PC 도우미도 같이 받아둬서 인터넷이 끊겨도 마지막 버전으로 보여줘요.
- 직접 쓴 문장이라 최근에 나왔거나 크게 바뀐 챔피언(`build_notes.py`의 `REVIEW` 목록)은 "(검토 필요)"로 표시돼요.

### 맞라인 상대별 문장

게임 플랜의 "내 역할"에 내 맞라이너(바텀은 상대 원딜·서폿 둘 다)를 상대하는 요령이 나와요. 같은 라인에 설 수 있는 모든 조합(약 12,800개)에 문장이 있어요.

- `data/traits.json`: 172개 챔피언 특성표 (사거리, 올인, 견제, 회복, 기동성, CC). 두 챔피언 특성을 비교해서 사거리·딜교환·회복·CC·후반 문장을 만들어요 (`matchup.js`).
- `data/pairs/*.json`: 자주 만나는 서폿·원딜 조합은 직접 쓴 문장이 있고, 있으면 먼저 보여줘요.
- 롤 통계(`data/stats.json`)에 그 조합이 10판 이상 있으면 라인전 유리·불리 판정은 통계 승률을 따라요.
- 바텀은 2:2로 따로 계산해요 (`matchup.js`의 `bot`). 원딜을 올인형·견제형·후반형, 서폿을 진입형·보호형·견제형·수비형으로 나눠 우리 바텀 궁합과 상대 바텀 궁합, 서폿 상성(진입 > 보호 > 견제 > 진입), 초반 2:2 힘을 비교해요. 라인별 우세의 BOT 점수, 게임 플랜의 "바텀 2:2", 서폿·원딜 추천 점수(내 원딜·서폿과의 궁합)에 반영돼요.
- 고친 뒤 `python scripts/build_matchups.py`를 실행하면 `data/matchups.json`이 만들어지고, `node tests/matchup.test.mjs`가 모든 조합을 만들어 보고 빈 문장·조사·모순을 검사해요. `node tests/matchup.test.mjs "파이크|쓰레쉬" SUP`처럼 한 조합만 볼 수도 있어요.

## 메타 반영 (최신 패치 승률)

추천 점수에 최신 패치 승률이 들어가요. 오래 쉬다 와도 그때 메타에 맞는 챔피언이 위로 올라오게 하려는 거예요.

- `.github/workflows/update-stats.yml`이 매일 새벽 3시 17분(KST)에 플래티넘·에메랄드 솔로랭크 경기를 Riot API로 최대 3,000판 더 받아 `data/stats.json`을 갱신해요. 저장소 Secrets에 `RIOT_API_KEY`가 있어야 돌아가요.
- 최신 패치 3개 경기만 남기고, 집계는 최신 패치(경기가 4,000판 미만이면 직전 패치까지)로 해요.
- 챔피언 승률은 판수가 적으면 같은 성향(진입형 서폿, 후반형 원딜, 탱커 탑 등) 평균 쪽으로, 성향 평균은 50% 쪽으로 당겨서 써요. 표본이 적은 챔피언도 성향 흐름은 따라가요.
- 승률 1%p가 추천 점수 0.8점이에요. 통계가 3주 넘게 지나면 절반만, 45일이 넘으면 반영하지 않고 추천 칸에 알려줘요.
- GitHub는 저장소에 60일 동안 활동이 없으면 예약 작업을 멈출 수 있어요. 추천 칸에 "통계가 N일 지났어요"가 보이면 Actions 탭에서 '통계 갱신'을 다시 켜주세요.

## 데이터는 어디서 오나요

| 항목 | 근거 |
|---|---|
| 0~10분 | 10분 시점 같은 포지션 상대와의 골드 차이 |
| 10~20분 | 10분→20분 사이 골드 차이 변화 |
| 20~30분 | 20분→30분 사이 골드 차이 변화 |
| 30분 이후 | 30분 넘게 진행된 경기의 승률 |
| 상성 | 같은 포지션 맞라이너 챔피언별 승률 (10판 이상, 표본이 적으면 50% 쪽으로 보정) |
| 한타 성향, 이니시·앞라인 태그 | 직접 매긴 추정값 |

통계는 [Riot 공식 API](https://developer.riotgames.com/)(League-V4, Match-V5 + 타임라인)로 한국 서버 랭크 솔로 경기를 모아 `scripts/collect.py`가 계산하고 `data/stats.json`에 저장해요. 표본이 적은 경기 수는 평균 쪽으로 보정하고, 30판 미만인 챔피언·포지션은 추정 표로 대체해요. `data/stats.json`이 없으면 페이지 전체가 추정 표로 동작해요.

op.gg 같은 통계 사이트를 직접 긁어오지 않는 이유는 대부분 이용약관에서 자동 수집을 금지하기 때문이에요.

## 통계 갱신하기

### 1. Riot API 키 받기
[developer.riotgames.com](https://developer.riotgames.com/)에 로그인하면 **개발 키**가 바로 나오지만 24시간마다 만료돼요. 자동 갱신을 쓰려면 같은 사이트에서 이 프로젝트를 등록하고 **Personal API Key**를 신청하세요. 누구나 보는 공개 페이지라서 프로젝트 등록이 필요해요.

### 2-a. 내 PC에서 직접 실행
```bash
export RIOT_API_KEY=RGAPI-xxxx   # Windows PowerShell: $env:RIOT_API_KEY="RGAPI-xxxx"
python scripts/collect.py --max-matches 1500
git add data/stats.json && git commit -m "통계 갱신" && git push
```
외부 패키지는 필요 없어요(Python 3.9 이상). 경기당 요청이 2번이라 기본 한도(2분에 100회)에서 1,500경기는 약 1시간 걸려요. 받은 경기는 `data/cache`에 저장돼서 다시 실행하면 이어서 받아요.

주요 옵션:

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--tiers` | `EMERALD,DIAMOND` | 수집할 티어 (예: `PLATINUM,EMERALD`) |
| `--max-matches` | `1500` | 최대 경기 수 |
| `--days` | `14` | 최근 며칠 경기만 |
| `--patches` | 최신 2개 패치 | 집계할 패치 (예: `26.21`) |
| `--min-games` | `30` | 이보다 적으면 통계 대신 추정값 사용 |

### 2-b. GitHub Actions로 매주 자동 갱신
1. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
2. 이름 `RIOT_API_KEY`, 값에 키 입력
3. **Actions → 통계 갱신 → Run workflow**로 바로 돌리거나, 매주 월요일 새벽에 자동 실행돼요.

## 아이디로 챔프폭 불러오기 (Cloudflare Worker)

페이지에 `이름#태그`를 넣으면 최근 랭크 경기(최대 100판)와 챔피언 숙련도를 보고 포지션별 챔프폭을 자동으로 채워요. Riot API 키를 페이지에 넣으면 누구나 볼 수 있어서, 키를 숨겨주는 작은 중계 서버(`worker/worker.js`)를 Cloudflare Workers 무료 플랜에 올려서 써요.

### 대시보드로 배포하기 (설치 없이, 15분)
1. [dash.cloudflare.com](https://dash.cloudflare.com/) 가입 (무료 플랜)
2. **Workers & Pages → Create → Create Worker** → 이름 `lol-pick-reader` → **Deploy**
3. **Edit code** → 기본 코드를 모두 지우고 [`worker/worker.js`](worker/worker.js) 내용을 붙여넣기 → **Deploy**
4. **KV 저장소 만들기:** 왼쪽 메뉴 **Storage & Databases → KV → Create** → 이름 `lol-pick-reader-pool`
5. Worker → **Settings → Bindings → Add → KV namespace** → 변수 이름 `POOL_KV`, 4번에서 만든 저장소 선택
6. Worker → **Settings → Variables and Secrets → Add**
   - `RIOT_API_KEY` : 종류 **Secret**, 값은 Riot API 키
   - `ALLOWED_ORIGIN` : 종류 **Text**, 값 `https://wandadj.github.io`
   - `ALLOWED_RIOT_IDS` : 종류 **Text**, 나와 지인 아이디를 쉼표로 (예: `동재#KR1, 친구#KR1`)
7. Worker 주소(`https://lol-pick-reader.<계정>.workers.dev`)를 `data/config.json`의 `poolApi`에 넣고 커밋

```json
{ "poolApi": "https://lol-pick-reader.<계정>.workers.dev" }
```

**지인 추가·삭제:** 6번의 `ALLOWED_RIOT_IDS` 값만 고치고 저장하면 돼요. 코드는 다시 붙여넣을 필요 없어요.

**데이터는 어디에?** 4번의 KV 저장소(내 Cloudflare 계정)에 아이디별로 저장돼요. 경기마다 내 포지션·챔피언·승패·시간만 남기고, 같이 한 다른 플레이어 정보는 저장하지 않아요. GitHub에는 올라가지 않아서 다른 사람은 볼 수 없어요.

### 명령줄로 배포하기 (Node.js가 있으면)
```bash
cd worker
npx wrangler deploy
npx wrangler secret put RIOT_API_KEY
```

### Personal Key로 쓸 때
Riot 정책상 **Personal API Key는 나 혼자나 작은 지인 모임용**이에요. 누구나 아무 아이디나 조회할 수 있게 열어두면 공개 서비스가 되어 Production Key가 필요해요. 그래서 `ALLOWED_RIOT_IDS`에 나와 지인 아이디만 넣어두세요. 등록되지 않은 아이디는 Riot API를 호출하기 전에 거절해요. Production Key를 받으면 `ALLOWED_RIOT_IDS`를 지우면 누구나 쓸 수 있어요.

PC 도우미를 쓰는 사람은 이 서버 없이도 자기 클라이언트에서 챔프폭을 불러올 수 있어요.

### 챔프폭은 어떻게 고르나요
- 아이디별로 랭크·빠른 대전·일반·신속 대전 경기를 **최근 300판**까지 쌓아요 (칼바람·아레나 제외).
- **수집은 불러오기 버튼을 누른 사람만** 해요. 한 번에 새 경기를 최대 35판 받고, 페이지를 열어두면 1분마다 이어서 받아서 처음 300판은 10분 정도면 채워져요. 그다음부터는 새 경기만 받아요.
- KV가 없으면 매번 최근 35판만 봐요.
- 포지션별 챔프폭 기준: 그 포지션에서 **2판 이상**, 또는 **1판 + 숙련도 3만 점 이상**. 주 포지션이거나 5판 이상 간 포지션이면 최근엔 안 했어도 **숙련도 5만 점 이상**인 챔피언을 포함해요.
- 추천 목록에 "내 기록 21판 12승 (57%)"처럼 표시하고, 5판 미만은 승률 대신 **표본 적음**으로 표시해요.

### 알아두기
- 한 번 불러올 때 Riot API를 최대 45번 정도 호출해요. 같은 아이디는 모든 경기를 받은 뒤 10분 동안 캐시돼요.
- Personal API Key 한도(2분에 100회)를 모두가 나눠 써요. 그래서 지인은 5~10명 정도가 적당하고, 여러 명이 동시에 처음 수집하면 "요청이 많아요"가 뜰 수 있어요. 페이지가 잠시 뒤 알아서 다시 시도해요.
- 키가 만료되면 페이지에 "서버의 Riot API 키가 만료됐거나 잘못됐어요"라고 떠요. Worker의 `RIOT_API_KEY`만 바꾸면 돼요.
