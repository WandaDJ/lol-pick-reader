# 매일 새 포지션·새 챔피언 설명 채우기

매일 아침 예약 작업이 이 문서대로 진행해요. 사람이 직접 할 때도 같은 순서예요.

## 1. 무엇을 채워야 하는지 확인

```
git pull
python scripts/missing_roles.py
```

통계(`data/stats.json`)에서 30판 이상, 그 챔피언 판수의 10% 이상인 챔피언·포지션 중 설명이 없는 것만 나와요. 하루에 많아야 10개까지만 채우고, 판수가 많은 것부터 해요. 목록이 비어 있으면 아무것도 바꾸지 않고 끝내요.

## 2. 새 포지션 (기존 챔피언)

목록에 나온 `챔피언 포지션`마다 세 군데를 채워요.

1. `index.html`의 `const R={...}`에서 그 포지션 줄 끝에 챔피언 이름을 추가하고, `matchup.js`의 그 포지션 성향 표(`LANE_TYPE` 또는 `ADC_TYPE`·`SUP_TYPE`)에도 넣어요.
2. 기본 세팅 한 줄: `data/setup/top.json`·`jgl.json`·`mid.json`, 원딜·서폿은 `data/setup/bot.json`의 `ADC`·`SUP` 안에 넣어요.
   - 형식: `주문 · 아이템 방향 · 역할` (예: `강타+점멸 · 공격력·물리 관통 아이템 · 6레벨 궁 암살과 카정`)
   - 아이템·룬 이름은 쓰지 않고 방향만 써요. 데이터가 30판 이상 쌓이면 페이지가 경기 데이터로 바꿔 보여줘요.
3. 포지션 전용 문장 7줄: `data/notes/lanes-auto.json`에 `"챔피언|포지션": [7줄]`로 넣어요. 파일이 없으면 `{}`로 만들어요.
   - 순서: 강해지는 시점, 0~10분, 10~20분, 20분 이후, 이기고 있을 때, 지고 있을 때, 이 챔피언을 상대할 때
   - 그 포지션에서 실제로 하는 일(정글이면 정글링·갱·카정, 서폿이면 원딜 보호·시야, 탑이면 웨이브·순간이동)을 구체적으로 써요.

## 3. 새 챔피언

`새 챔피언: 기본 문장·특성표부터 필요`로 나오면 웹에서 스킬을 조사한 뒤 여섯 군데를 채워요.

1. `index.html`의 `const D={...}`: `"이름":[초반, 중반, 후반, 한타, "태그"]` (1~5점, 태그 E 이니시·F 앞라인·P 보호·S 스플릿·M 마법·A 물리)
2. `index.html`의 `const R={...}`: 통계에 나온 포지션들
3. `data/traits.json`: `[사거리 1~3, 올인, 견제, 회복, 기동성, CC]` (0~3)
4. `data/notes/7.json` (없으면 만들기): 기본 문장 7줄. 챔피언 이름은 통계·Data Dragon의 한국어 이름과 같게(띄어쓰기는 상관없음)
5. 기본 세팅: 2번과 같은 방법.
6. 성향: `matchup.js`에서 탑·정글·미드는 `LANE_TYPE`(`put('TOP', ...)` 줄), 원딜·서폿은 `ADC_TYPE`·`SUP_TYPE`에 주 성향을 추가해요. 두 역할을 실제로 하는 챔피언이면 `SUB_TYPE`(`sub('TOP', ...)` 줄)에 보조 성향을 최대 2개까지 넣어요(예: `사일러스:mcarry`). 상성 계산은 주 성향만 쓰고, 추천 점수의 메타·내 성향 보정에서 주 80%·보조 20%로 섞여요.

## 4. 문장 규칙

- 존댓말 "-요"체, 짧고 쉬운 문장. 한 문장에 할 일 하나.
- 공식 스킬 이름이 확실하지 않으면 이름 없이 `Q`, `E(돌진)`처럼 키와 짧은 설명만 써요.
- 숫자(쿨타임 등)는 확실할 때만 써요.
- 다른 챔피언·포지션 문장을 복사하지 말고 그 챔피언 키트에 맞게 써요.
